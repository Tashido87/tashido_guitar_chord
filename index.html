📝 How to write lyrics with chords: Put chords in brackets right before the syllable, e.g. [G]ကိုယ် ရေးခဲ့သော [Em]သီချင်းတွေ.
Sections can be marked like Intro:, Verse 1:, Chorus:, Solo:, or Ending:.
🎯 Chord နေရာချိန်ညှိရန် လမ်းညွှန်:
• ◂ / ▸ ခလုတ်များ: Chord တစ်ခုချင်းစီကို ဘယ်/ညာ စာလုံးတစ်လုံးချင်း အလွယ်တကူ ရွှေ့နိုင်ပါသည်။
• စာသားကို Click နှိပ်ခြင်း: မည်သည့်စာလုံးပေါ်မဆို Click နှိပ်လိုက်ပါက ရွေးထားသော Chord ထိုနေရာသို့ ချက်ချင်းပြောင်းရွှေ့သွားပါမည်။
• ✕ ခလုတ်: မလိုချင်သော Chord ကို ဖျက်နိုင်ပါသည်။

☁️ Firebase Cloud Database

Google Firebase Firestore နှင့် ချိတ်ဆက်ပြီး သီချင်းဒေတာများကို Cloud ပေါ်တွင် အမြဲသိမ်းဆည်းထားနိုင်ပါသည်။ Browser data ရှင်းလိုက်သော်လည်း သီချင်းများ မပျက်တော့ဘဲ အခြား Device များမှလည်း ကြည့်ရှုနိုင်မည်ဖြစ်ပါသည်။

💡 Firebase Config ရယူနည်း: Firebase Console > Project Settings > General > Your apps > Web config ကို copy ကူးထည့်ပါ။ Firestore Database ဖွင့်ထားပေးရန် လိုအပ်ပါသည်။
