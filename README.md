# Tashido Guitar Chord — Clean Acoustic Songbook 🎸

သန့်ရှင်းသပ်ရပ်ပြီး မျက်စိမညောင်းစေသော Pure White & Soft Slate Theme ဖြင့် ဖန်တီးထားသော Guitar Chord & Lyrics Web Application ဖြစ်ပါသည်။

---

## ✨ အဓိကထူးခြားချက်များနှင့် အသစ်ပါဝင်သော Features များ

1. **သန့်ရှင်းသော အဖြူရောင် ဒီဇိုင်း (Clean White Minimalist Aesthetic)**:
   - မျက်စိစူးစေသော အပြာရောင် gradient များနှင့် glow များကို ဖယ်ရှားပြီး Pure White (`#ffffff`), Soft Slate (`#0f172a`, `#334155`) ဖြင့် သက်တောင့်သက်သာရှိစေရန် ပြင်ဆင်ထားပါသည်။

2. **သီးသန့် Lyrics Scroll စနစ် (Independent Scroll Area)**:
   - Sidebar၊ Song Header၊ Tool Panels များနှင့် Player Bar တို့ မရွေ့မလျားဘဲ Fixed ငြိမ်နေပြီး **သီချင်းစာသား (Lyrics Card) နေရာတစ်ခုတည်းသာ သီးသန့် Scroll** (Manual Scroll & Auto-Scroll) ဖြစ်စေရန် ပြုလုပ်ထားပါသည်။

3. **🇲🇲 Myanmar Songs နှင့် 🇬🇧 English Songs ခွဲခြားကြည့်ရှုနိုင်ခြင်း**:
   - ဘယ်ဘက် Sidebar တွင် `All Songs` အပြင် `🇲🇲 Myanmar Songs` နှင့် `🇬🇧 English Songs` သီးသန့် Filter Tab များ ထည့်သွင်းထားပါသည်။
   - သီချင်းအသစ်ထည့်လျှင် စာသားထဲရှိ မြန်မာစာယူနီကုဒ်ကို Auto Detect လုပ်ကာ သက်ဆိုင်ရာ ကဏ္ဍထဲသို့ အလိုအလျောက် ခွဲခြားထည့်သွင်းပေးပါသည်။

4. **✨ Gemini AI ဖြင့် Chord Sheet ဓာတ်ပုံ Scan ဖတ်ခြင်း (`gemini-flash-latest`)**:
   - ဂစ်တာ Chord စာရွက် ဓာတ်ပုံကို Drag & Drop သို့မဟုတ် <kbd>Ctrl+V</kbd> / <kbd>Cmd+V</kbd> Paste လုပ်လိုက်ရုံဖြင့် စာသားနှင့် Chord များကို နေရာတကျ ချက်ချင်းဖတ်ထုတ်ပေးပါသည်။
   - **Watermarks (ဥပမာ- `NT LYRIC & CHORD`)၊ Website link၊ Ads နှင့် မလိုလားအပ်သော စာ/ပုံများကို အလိုအလျောက် စွန့်ပစ် (Auto Discard)** ပေးပါသည်။
   - သီချင်းအမည်၊ အဆိုတော်၊ မူရင်း Key၊ Capo များကိုပါ တစ်ပါတည်း ဖြည့်ပေးပါသည်။

5. **🎯 Visual Chord Aligner (Chord နေရာရွှေ့/ချိန်ညှိသည့်စနစ်)**:
   - Add/Edit Modal ထဲတွင် `◂` နှင့် `▸` ခလုတ်များဖြင့် Chord များကို စာလုံးတစ်လုံးချင်း ဘယ်/ညာ စိတ်ကြိုက် နေရာရွှေ့နိုင်ပါသည်။
   - Chord အမည်ပြင်ခြင်း၊ ဖျက်ခြင်း (`✕`) နှင့် Chord အသစ်ထည့်ခြင်း (`+ Chord`) တို့ကို လွယ်ကူစွာ ပြုလုပ်နိုင်ပါသည်။

6. **Web Audio စနစ်ဖြင့် တကယ့် Acoustic Guitar သံစဉ်များ ကြားနိုင်ခြင်း**:
   - Chord များကို click နှိပ်ရုံဖြင့် ဂစ်တာတီးခတ်သံအစစ် ထွက်ပေါ်လာမည်ဖြစ်ပြီး "Strum All" ခလုတ်လည်း ပါဝင်ပါသည်။

7. **ဂစ်တာလေ့ကျင့်ရန် Tools များ**:
   - **Smart Transpose**: Key ပြောင်းလျှင် Chord များနှင့် Diagram များ ချက်ချင်း ပြောင်းလဲခြင်း။
   - **Capo Selector**: Capo 0 မှ 12 အထိ ချိန်ညှိနိုင်ခြင်း။
   - **Guitar Tuner Tone**: Standard E, A, D, G, B, e ကြိုးညှိအသံများ ပါဝင်ခြင်း။
   - **Metronome**: BPM ချိန်ညှိနိုင်သော Beat အချက်ပြ Metronome။
   - **Print Chord Sheet**: စာရွက်ဖြင့် ပရင့်ထုတ်ရန် Clean Print Layout။
